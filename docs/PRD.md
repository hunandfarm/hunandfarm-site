# 사이트 설계도(PRD) — 훈앤팜

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
성주 산속에서 미인고추와 김장배추를 기르는 훈앤팜 농장을 알리고, 주문 문의를 받는 사이트.

## 2. 손님
- 누가: 도시에 살면서 산지 배추·고추로 직접 김장하는 가족
- 어디서 알고 오나: 인스타그램, 카카오톡 채널 (→ 휴대폰으로 먼저 본다. 모바일 화면 우선)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 어떻게 키웠는지 (성주 산속 환경, 재배 방법) — 사용자가 고른 가장 중요한 질문
2. 가격·판매 단위 (8번에 적은 가격을 보여 준다)
3. 수확·배송 시기 (미정 — 사용자가 고르지 않음, 만들 때 자리만 둔다)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 농장·밭 사진 (사용자가 가지고 있음 — 만들 때 받아서 넣는다)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 주문 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로, 한 페이지)
1. 첫 화면 — 산속 밭 사진 + 한 문장 + [주문 문의하기] 버튼
2. 이렇게 키웁니다 — 성주 산속 농장 이야기, 밭 사진
3. 기르는 작물과 가격 — 미인고추 풋고추 1kg 10,000원, 쌈배추 1포기 3,000원, 김장배추 (가격 준비 중) · 받는 시기는 "준비 중"
4. 후기 자리 (비워 둠)
5. 주문 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 하고 싶은 말 (원하는 품목·수량·날짜도 여기에 자유롭게 쓰도록 안내 문구를 둔다)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격:
  - 미인고추 풋고추 1kg 10,000원
  - 쌈배추 1포기 3,000원
  - 김장배추: (미정 — 준비 중)
- 시간(수확·배송 시기): (미정 — 준비 중)
- 위치: 경북 성주 산속 (자세한 주소 미정)
- 연락 방법: (미정 — 카카오톡 채널 주소·전화번호 받으면 넣는다)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인 (사용자가 고름)
- 온라인 결제 (기본으로 미룸 — 지금은 문의 후 농장이 연락)
- 블로그·농사 일기, 사진 올리기, 알림 메일

## 10. 첫 화면 한 문장 후보
1. 성주 산속 맑은 바람이 키운 미인고추와 김장배추
2. 올해 김장은 산에서 자란 배추로 — 훈앤팜
3. 산속 밭에서 바로, 우리 집 김장 재료

## 11. 다음에 할 것
- 김장배추 가격, 수확·배송 시기, 연락처 채우기
- 실제 손님 후기가 생기면 후기 칸 채우기
- 필요해지면 온라인 결제, 회원가입(이때 개인정보 처리방침 필요)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 (흙·햇살 느낌, 시골 농장의 정감) · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
